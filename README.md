# Coopervida — Fase 1 (dossiê Festval)

Checklist em português para a Fase 1: auditoria de conformidade, planejamento de
produção e arquitetura de marca antes do contato com a Rede Festval.

## Uso

```bash
npm install
npm run dev
```

Abra a URL local. O progresso fica no `localStorage` do navegador. Use **Baixar
índice** para exportar JSON. A Fase 2 só libera quando os 34 documentos estiverem
válidos; o e-mail para `sac@superfestval.com.br` e `compras@superfestval.com.br`
é apenas demonstração.

## Qualidade

```bash
npm run validate
```
